# Claude Code Guide — SDK-022

```text
Implement a production prompt registry and lifecycle service.

Define prompt, version, variable, schema, model constraint, environment and approval contracts. Implement safe rendering, validation, immutable version history, draft-review-evaluate-approve-publish-deprecate-rollback, exact version resolution, diffs, audit hooks, authorization, backup/restore and migration.

Add injection/rendering/security tests, concurrency and rollback tests, evaluation gate integration, customer administration, deployment/configuration, metrics/alerts and incident runbooks. Never store credentials in prompt content or silently mutate a published version.
```
