# Claude Code Guide — SDK-024

```text
Implement SDK-024 as governed production memory, not a conversation dump.

Define memory type, scope, subject, provenance, confidence, classification, consent, retention and lifecycle contracts. Implement policy-controlled writes, validation, deduplication, consolidation, retrieval, budgeting, correction, expiration, deletion, authorization and reconciliation using provider-neutral adapters.

Add privacy/prompt-injection threat tests, retention/deletion and authorization tests, quality and load tests, backup/restore, metrics/alerts, customer governance configuration, deployment and incident runbooks. Never let inferred memory become authoritative enterprise data without an approved domain workflow.
```
