# Claude Code Guide — SDK-030

```text
Implement a production governed analytics framework.

Define metric, KPI, dimension, measure, grain, time, lineage, quality and query contracts. Implement event/batch ingestion, validation, deduplication, late data, aggregation, semantic queries, snapshots, correction/backfill, reconciliation, retention and AI usage analytics.

Add production analytical adapters, data-quality rules, lineage, load/scale/cost tests, backfill and outage tests, dashboards/alerts, customer semantic catalog, deployment, backup/recovery and operations runbooks. Do not mix raw operational telemetry with governed business metrics without explicit contracts.
```
