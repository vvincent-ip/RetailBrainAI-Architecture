# Claude Code Guide — SDK-020

```text
Implement SDK-020 as production compliance control infrastructure, not as a claim of automatic legal certification.

Define policies, control mappings, classifications, purposes, consent, retention, deletion requests, legal holds, evidence, exceptions and approvals. Implement versioned policy evaluation, request workflows, owning-SDK integration contracts, reconciliation, segregation of duties, audit and evidence export.

Add regulatory-profile configuration, conflict and deadline tests, retention/erasure/legal-hold integration tests, security tests, dashboards/alerts, customer control matrix, deployment, migration and compliance operations runbooks. Mark all required customer/legal decisions explicitly.
```
